# XiaoCalc 1.1.1

**精确形式**：保留根号与 π，不再只能给浮点近似值。

作业里要求「保留根号」「结果用 π 表示」时，普通计算器只能给出小数；
这一版可以直接给出精确值。

```
√8            →  2√2
√2×√3         →  √6
2√2+3√2       →  5√2      同类项自动合并
√18-√8        →  √2       先化简再合并
π√2           →  π√2      根号与 π 同时出现也保留
2π/3          →  2π/3
π+1           →  π+1
```

在 **设置 → 计算规则** 中打开「保留根号」与「保留特殊符号」即可（两者默认关闭）。
根号看前者，π / e 看后者；只开一个而所需的符号未被允许时会回落小数，
不会出现 `3.14159√2` 这种半符号半小数的混合结果。

## 本版还包括

- 新增自然对数 `ln`
- 函数页键位调整：末行重复的分页键改为 `ln`；`√` 与 `^` 互换，
  使两个二元运算符在右列相邻、与主键盘的运算符列对齐
- 重做键面配色层级：数字 > 函数 > 工具三级中性色，
  红色只表示二元运算符，`C` 清空改用错误色强调，分页键改为胶囊形
- 修复角度单位键无反馈的问题（键面现在显示当前单位，按下当场变化）

## 已知边界

精确形式只覆盖**加减乘除构成的表达式**。以下情况仍回落为小数：

- 括号内做加减，如 `(1+√2)÷4`
- 除数为根号，如 `1÷√2`
- 含函数，如 `sin(π÷6)`

符号式在输出前会与真实结果做**数值反验**，因此解析边界只会表现为「没化简」，
不会给出错误答案。
