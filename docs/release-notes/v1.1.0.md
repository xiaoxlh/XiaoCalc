# XiaoCalc 1.1.0

首个公开发布版本。面向安卓手表的离线计算器，圆屏与方屏均已适配。

## 功能

- 四则运算与常用函数：`sin` `cos` `tan` `ln` `√` `^` `mod` `π` `e`，支持括号嵌套
- 两组键位：数字页与函数页，底部胶囊一键切换；在函数页按下函数后**自动回到数字页**，少按一次
- 结果格式化：科学计数法、千分位分隔、超长结果自动缩放字号
- 角度制 / 弧度制切换，当前单位直接显示在按键上
- 历史记录本地持久化，点击可回填
- 支持旋转表冠滚动列表
- 按键触感反馈，可关闭

## 适配

- 圆屏按几何弦长逐行贴合，键盘随表盘形状自然收窄
- 方屏限制键长宽比并居中，不与圆屏共用一套硬编码数值
- 任意分辨率按设计单位等比缩放

## 隐私

- **不联网**：未声明网络权限
- 设置与历史记录仅存于应用私有目录，卸载即清除

## 安装

```bash
adb install -r XiaoCalc-1.1.0.apk
```

> 若设备上已装过其他签名的版本，需先卸载——签名不同的 APK 无法覆盖安装，
> 卸载会一并清除历史记录与设置。

## 已验证环境

小米手表 M2505W1，Android 14，480×480 @320dpi，圆形。

方屏布局由无设备渲染测试覆盖，尚未在方屏真机上验证。

## 已知限制

- 圆屏上按键偏宽偏矮：键宽由该行弦长决定，键高受纵向预算限制
- 键盘固定 4 列，`(` `)` 等符号位于函数页
- 表冠滚动依赖系统是否向第三方应用派发旋转事件；可在「设置 → 诊断信息」查看硬件识别情况
- 非精密计算工具，请勿用于要求高精度或高可靠性的场合
